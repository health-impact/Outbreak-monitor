# Libya EWS — منظومة الإنذار المبكر للأوبئة (المرحلة 1)

خط البيانات: جلب ← ربط بمرض ودولة ← تحقق (رسمي أو مصدران مستقلان) ← `data/events.json`.

## تشغيل محلي
    pip install pyyaml pytest
    pytest -q
    python -m ews.pipeline

## ملاحظات
- روابط المصادر في `config/sources.yaml` تحتاج تأكيداً عند أول تشغيل: راجع `data/source_health.json`.
- المصادر الوطنية (ليبيا، تونس، مصر، الجزائر) معطّلة حتى تحديد الرابط الرسمي.
- لا يُعتمد أي مصدر غير رسمي إلا بتأكيد جهتين مختلفتين خلال 7 أيام.
